# Component Snapshot Tests

This directory contains snapshot tests for all React components. Snapshot testing captures the complete HTML structure generated by components, making it easy to:

- **Trace HTML structure** - View exact rendered HTML in `__snapshots__/` files
- **Detect unintended changes** - Tests fail if component output changes unexpectedly
- **Document component behavior** - Snapshots serve as living documentation

## Important: Type Checking Test Files

**Note:** Next.js `npm run build` does NOT type-check test files. TypeScript errors in `__tests__/` won't break the build.

To check TypeScript errors in test files:
```bash
npx tsc --noEmit
```

This checks ALL files including tests. See CLAUDE.md for more details.

## Running Tests

```bash
# Run all tests once
npm test

# Run tests in watch mode (auto-rerun on file changes)
npm run test:watch

# Run tests with UI (visual test runner)
npm run test:ui

# Update snapshots when component changes are intentional
npm run test:update
```

## Viewing HTML Structure

To trace the HTML structure of a component:

1. Look in the `__snapshots__/` directory for the corresponding `.snap` file
2. Find the test name you're interested in
3. The snapshot shows the complete HTML structure with:
   - Element hierarchy
   - CSS classes
   - Attributes
   - Text content

**Example:** To see the HTML structure of `ContactForm`, open:
```
components/__tests__/__snapshots__/ContactForm.test.tsx.snap
```

## When Snapshots Fail

Snapshots fail when component HTML output changes. This could be:

1. **Intentional change** - You modified the component
   - Review the diff to confirm changes are correct
   - Run `npm run test:update` to update snapshots

2. **Unintentional change** - Something broke
   - Review the diff to identify the issue
   - Fix the component to restore expected output

## Adding New Snapshot Tests

To add snapshot tests for a new component:

```tsx
import { describe, it, expect } from "vitest";
import { render } from "@testing-library/react";
import { YourComponent } from "../YourComponent";

describe("YourComponent", () => {
  it("renders and matches snapshot", () => {
    const { container } = render(<YourComponent />);
    expect(container.firstChild).toMatchSnapshot();
  });
});
```

Run `npm test` to generate the initial snapshot.
